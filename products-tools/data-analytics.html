What are IBM Synthetic Data Sets?

IBM Synthetic Data Sets are enterprise-grade, artificially generated datasets designed for AI model development in financial services. They look and behave like real transaction data — with no real customer information — making them safe to use for building, testing, and demonstrating AI models without requiring access to production data.

One of the most common blockers in early-stage AI projects on IBM Z is data access. Getting approved access to production data takes time, and in regulated industries it may have restrictions that make it difficult to use freely for development. Synthetic Data Sets remove that blocker, letting teams move from idea to working model without waiting on data approvals.

Why Use It

  • Removes the data access blocker — No need to request, anonymize, or wait for production data. Start building immediately.
  • Realistic financial services data — Datasets reflect the statistical properties and patterns of real financial transactions, not random noise.
  • No seed data required — IBM generates the data entirely. Clients don't need to provide any real data to get started.
  • Privacy and compliance safe — No real customer data means no GDPR, PCI-DSS, or privacy concerns during development and demos.
  • Covers three lifecycle stages — Use the same datasets to build a model, validate it, and demonstrate results.

Scikit-learn & XGBoost

Model Runtime & Optimization

IBM Z provides hardware-accelerated runtime libraries and compiler tooling to maximize AI inference performance on Telum and Spyre processors.

IBM Z Deep Neural Network Library (zDNN)

zDNN is a low-level C library that exposes the Telum AI accelerator to software. It provides implementations of common neural network operations offloaded to the Telum on-chip AI engine.

  • Tensor operations for feedforward and recurrent networks
  • Telum I support: LSTM, GRU, Conv2D, Pooling, Activation functions, Matmul, Softmax, BatchNorm, and more
  • Telum II additions: LSTM, Subtract, Quantized Matmul, Moments, Mean Reduce, Exp, Inverse Square Root
  • C API usable directly or via higher-level framework integrations
Learn more about zDNN on GitHub →

IBM Z Deep Learning Compiler (IBM zDLC)

The IBM Z Deep Learning Compiler automatically compiles ONNX models for execution on Telum, inserting zDNN calls where applicable. It replaces manual operator-by-operator integration and enables end-to-end optimized inference from a standard model format.

  • ONNX model input → optimized s390x binary output
  • Automatic zDNN dispatch for acceleratable operators
  • Fallback to CPU for unsupported operators
  • No manual zDNN integration required by developers

IBM AI Optimizer for IBM Z

IBM AI Optimizer helps data scientists and engineers optimize models for IBM Z deployment. It supports quantization and pruning techniques to reduce model size and improve inference throughput without significant accuracy loss.

  • Post-training quantization (INT8, FP16)
  • Model pruning for size reduction
  • Performance benchmarking tools for Z targets
  • Integration with standard ONNX and TensorFlow model formats

ONNX Runtime on IBM Z

ONNX Runtime is an open-source inference engine for ONNX models. On IBM Z, it is used as the execution backend for compiled models, with zDNN-based acceleration available for supported operations.

  • Runs ONNX models natively on Linux on IBM Z (s390x)
  • Works with IBM zDLC-compiled models
  • Broad framework coverage: TensorFlow, PyTorch, scikit-learn (via ONNX export)

Inference & Serving Technologies

IBM Z provides enterprise-grade model serving tools for both traditional AI and generative AI workloads, supporting REST APIs, containerized serving, and LLM inference at scale.

IBM vLLM for Spyre (vllm-spyre)

IBM maintains a fork of the vLLM inference engine with a custom execution backend for IBM Spyre accelerators. It enables high-throughput generative AI inference with LLMs on IBM Z using Spyre FP16 and GPTQ quantized models.

  • LLM inference with IBM Spyre acceleration
  • FP16 and GPTQ (W4A16) quantization support
  • Decoder-only and encoder/embedding model support
  • OpenAI-compatible REST API
  • Tensor parallelism for multi-card deployments
Learn more about vLLM for Spyre on GitHub →

IBM Z Accelerated for Triton Inference Server

NVIDIA Triton Inference Server, optimized for IBM Z, provides a flexible multi-framework model serving solution. It supports models from TensorFlow, ONNX, and other formats under a unified serving interface.

  • Multi-framework model serving (TF, ONNX, custom backends)
  • HTTP and gRPC inference endpoints
  • Dynamic batching for throughput optimization
  • Model repository management

IBM Z Accelerated Serving for TensorFlow (TF Serving)

IBM Z Accelerated Serving for TensorFlow provides production-grade model serving for TensorFlow SavedModel format, optimized for Z hardware acceleration.

  • Serve TensorFlow SavedModels via gRPC or HTTP/REST
  • Telum-accelerated inference via TensorFlow + zDNN integration
  • Version management and hot model reload

Red Hat AI Inference Server

Red Hat AI Inference Server is an enterprise-grade serving platform built on top of vLLM, optimized for OpenShift deployments. On IBM Z, it provides a standardized serving layer for foundation models and LLMs within Red Hat OpenShift AI.

  • OpenAI-compatible API surface
  • Integration with Red Hat OpenShift AI model serving pipelines
  • Scalable inference across OpenShift on IBM Z

AI Platforms

  • JupyterHub-based data science workbenches
  • Kubeflow Pipelines for ML workflow automation
  • Model serving with Triton and KServe
  • Model registry and versioning
  • Bias detection and model monitoring

IBM watsonx.ai is IBM's AI studio for enterprise AI development, combining traditional ML, AutoML, and foundation model capabilities. It supports hybrid deployment patterns where models trained or fine-tuned in watsonx.ai can be deployed for inference on IBM Z.

  • Foundation model access (Granite and partner models)
