Snap Machine Learning (Snap ML) for IBM LinuxONE

AI Lifecycle: Prepare Data · Train Model

Snap ML is an IBM library developed and maintained by IBM Research that provides high-speed training and inference of popular machine learning models. It is fully compatible with the scikit-learn Python API and addresses the core ML needs of data scientists: speed, resource efficiency, accuracy, and scalability to TB-scale datasets.

It targets structured/tabular data workloads using popular statistical models, including Generalized Linear Models (Linear/Logistic Regression, SVMs), Decision Trees, Random Forests, and Gradient Boosting Machines.

Instead of replacing existing workflows, Snap ML acts as a high-performance drop-in replacement for standard machine learning libraries like scikit-learn or LightGBM.

What Snap ML Supports

  • Generalized Linear Models, Tree-based Models, and Gradient Boosting Machines
  • Accelerated scoring of scikit-learn, XGBoost, and LightGBM trained models when exported to PMML, JSON, or ONNX
  • Drop-in scikit-learn compatible API — no code changes required
  • Scalable to TB-scale datasets

IBM Telum Integrated Accelerator for AI

Starting with Snap ML version 1.9.0, Snap ML can utilize the IBM Integrated Accelerator for AI. Accelerator exploitation can be enabled at model import time for:

  • Random Forest
  • Extra Trees
  • Gradient Boosting Machines

Starting with Snap ML 1.9.1, SnapML-trained tree-based models (RF, ET, and GB) can be exported to PMML.

TensorFlow for IBM LinuxONE

AI Lifecycle: Train Model · Deploy Models

Overview

TensorFlow is a popular open-source machine learning and artificial intelligence framework developed by Google. It provides an end-to-end ecosystem of tools, libraries, and community resources that allow developers to design, train, and deploy deep learning models. Built around the concept of multidimensional data arrays known as "tensors," TensorFlow excels at complex tasks such as computer vision, natural language processing, and predictive analytics.

TensorFlow can be used on IBM LinuxONE on Linux environments and z/OS Container Extensions. On IBM LinuxONE, TensorFlow is built to exploit the vector architecture for training and inference operations. On IBM LinuxONE 4 and 5 hardware, TensorFlow can now leverage new acceleration capabilities enabled by the Telum I and Telum II processors.

With TensorFlow Serving, you can expose REST and gRPC endpoints for model inference requests. This supports high throughput, low latency inference serving.

TensorFlow for IBM LinuxONE

On IBM LinuxONE 4, 5 machines (running Linux containers), TensorFlow core Graph Execution will leverage new inference acceleration capabilities that transparently target the IBM Integrated Accelerator for AI through the IBM z Deep Neural Network (zDNN) library. The IBM zDNN library contains a set of primitives that support Deep Neural Networks. These primitives transparently target the IBM Integrated Accelerator for AI on IBM LinuxONE 4 and later. This leads to AI acceleration using the integrated Neural Network Assist (NNPA) instructions of the IBM Telum On-chip Accelerator. No changes to the original model are needed to take advantage of the new inference acceleration capabilities.

TensorFlow Serving for IBM LinuxONE

With TensorFlow Serving, you can expose REST and gRPC endpoints for model inference requests, supporting high-throughput, low-latency inference serving on IBM LinuxONE for TensorFlow Models.

PyTorch for IBM LinuxONE

AI Lifecycle: Train Model · Deploy Models

PyTorch is one of the most popular open source AI frameworks in the world that provides a flexible platform for building deep learning models. Released by Facebook's AI Research lab in 2016, PyTorch allows developers to create and modify models easily through its dynamic structure, which offers immediate feedback. This adaptability makes it particularly appealing for researchers and developers who want to experiment with new ideas.

In PyTorch, you create models by writing a Python program that specifies the layers and tensor-based operations of the deep neural network and compiling them into a model. Its focus on simplicity, low CPU usage, efficient memory management, and a robust community and ecosystem make it a strong choice for AI applications of all sizes.

PyTorch for IBM LinuxONE To Utilize IBM Telum Processors

To maximize PyTorch performance on IBM LinuxONE servers, AI Acceleration is done using the integrated Neural Network Assist (NNPA) instructions of the IBM Telum On-chip Accelerator. The AI Toolkit for IBM LinuxONE container images include IBM enhancements that enable open-source libraries to use these hardware acceleration capabilities. PyTorch applications that run with the PyTorch for LinuxONE container image can use this hardware acceleration in a manner similar to how PyTorch applications use AI accelerators on other platforms.

PyTorch for IBM LinuxONE can be leveraged for various use cases, including applications such as language processing and computer vision. It is optimized for AI on IBM LinuxONE 4 and 5 which improves inference performance for a wide range of PyTorch models.

PyTorch for IBM LinuxONE is offered as Linux Containers for LinuxONE users.
