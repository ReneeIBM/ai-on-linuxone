IBM Z Accelerated SnapML

AI Lifecycle: Prepare Data · Train Model

Snap ML is an IBM library developed and maintained by IBM Research that provides high-speed training and inference of popular machine learning models. It is fully compatible with the scikit-learn Python API and addresses the core ML needs of data scientists: speed, resource efficiency, accuracy, and scalability to TB-scale datasets.

What Snap ML Supports

  • Generalized Linear Models, Tree-based Models, and Gradient Boosting Machines
  • Accelerated scoring of scikit-learn, XGBoost, and LightGBM trained models when exported to PMML, JSON, or ONNX
  • Drop-in scikit-learn compatible API — no code changes required
  • Scalable to TB-scale datasets

IBM Telum Integrated Accelerator for AI

Starting with Snap ML version 1.9.0, Snap ML can utilize the IBM Integrated Accelerator for AI. Accelerator exploitation can be enabled at model import time for:

  • Random Forest
  • Extra Trees
  • Gradient Boosting Machines

Starting with Snap ML 1.9.1, SnapML-trained tree-based models (RF, ET, and GB) can be exported to PMML.

Getting Started

IBM Snap ML is available as part of Machine Learning for z/OS, as well as for IBM LinuxONE and Linux on Z (including z/OS Container Extensions). Container images are available in the IBM Z and LinuxONE Container Image Registry under ibmz-accelerated-for-snapml. Snap ML can also be installed directly via PyPI:

pip install snapml

IBM Z Accelerated for TensorFlow

AI Lifecycle: Train Model · Deploy Models

TensorFlow is an open source machine learning framework with a comprehensive set of tools that enable model development, training, and inference — including a rich and robust ecosystem. IBM Z Accelerated for TensorFlow runs on Linux on IBM Z and LinuxONE, including z/OS Container Extensions.

IBM Telum Integrated Accelerator for AI

On IBM z16, LinuxONE 4, and later machines (including z/OS Container Extensions), TensorFlow core Graph Execution leverages inference acceleration that transparently targets the IBM Integrated Accelerator for AI through the IBM Z Deep Neural Network (zDNN) library. This support extends to the Telum II processor on IBM z17. No changes to the original model are needed to take advantage of this acceleration.

TensorFlow Serving

With TensorFlow Serving, you can expose REST and gRPC endpoints for model inference requests, supporting high-throughput, low-latency inference serving on IBM Z and LinuxONE.

IBM Z Accelerated for PyTorch

AI Lifecycle: Train Model · Deploy Models

PyTorch is an open source machine learning framework that provides a flexible platform for building deep learning models. Released by Facebook's AI Research lab in 2016, PyTorch allows developers to create and modify models easily through its dynamic structure, which offers immediate feedback. This adaptability makes it particularly appealing for researchers and developers who want to experiment with new ideas.

PyTorch can be used on IBM zSystems and LinuxONE on Linux environments (including z/OS Container Extensions).

IBM Z Accelerated for PyTorch can be leveraged for various use cases, including applications such as language processing and computer vision. It is optimized to exploit the acceleration of IBM Z Integrated Accelerator for AI on IBM z16 and LinuxONE 4, which improves inference performance for a wide range of PyTorch models.
