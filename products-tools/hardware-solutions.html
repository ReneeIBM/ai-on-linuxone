AI on IBM LinuxONE 101

Hardware Accelerators

Telum II and Spyre are the two AI accelerators available with IBM LinuxONE 5. Telum II has an on-chip AI accelerator designed for real-time inference on traditional ML and deep learning models. IBM Spyre Accelerator is a separate card-based accelerator built for generative AI and large model workloads.

IBM Integrated Accelerator for AI (Telum)

What is the IBM Integrated Accelerator for AI?

The IBM Integrated Accelerator for AI is an on-chip AI accelerator available on the IBM Telum chip, part of IBM LinuxONE 4 and IBM LinuxONE 5 servers. It is designed to enable high-throughput, low-latency inference for deep learning and machine learning workloads.

You can build and train your models on any platform, including Linux on IBM LinuxONE. When you are ready to deploy, your models receive transparent acceleration and optimization on-chip, leveraging the best available acceleration for the model type.

The IBM Integrated Accelerator for AI is more than just a matrix multiplication accelerator. It provides optimization and acceleration for a broad set of complex functions commonly found in deep learning and machine learning models, enabling a wider range of AI operations to run directly on-chip.

Why the Integrated Accelerator?

  • On-chip, no GPU required – AI inference runs directly on the Telum processor with no external accelerator required for many AI workloads.
  • High throughput, low latency – Designed to support real-time inferencing for enterprise applications, helping organizations make AI-driven decisions close to their data.
  • Transparent acceleration – Supported frameworks automatically offload eligible operations to the accelerator without requiring application redesign or model rewrites.
  • Security and compliance – AI workloads run on the same highly secure LinuxONE platform where enterprise applications and data reside, helping reduce data movement while supporting governance and compliance requirements.

Using the Integrated Accelerator for AI

Depending on your model type, there are a few essential approaches to leveraging the Integrated Accelerator for AI. These capabilities are available through IBM offerings and open-source software on LinuxONE.

For Deep Learning Models (PyTorch, TensorFlow):

  • ONNX models compiled with the IBM Z Deep Learning Compiler (zDLC)
  • IBM Z Accelerated for TensorFlow
  • IBM Z Accelerated for PyTorch

These solutions can transparently leverage Integrated Accelerator capabilities available on LinuxONE.

For Traditional Machine Learning Models (scikit-learn, XGBoost, LightGBM):

  • IBM Z Accelerated SnapML – optimized training and inference with accelerator support for machine learning workloads.

For Framework and Compiler Developers:

  • IBM zDNN – a low-level library that exposes Integrated Accelerator capabilities to frameworks and compilers. Available on major Linux distributions including Red Hat Enterprise Linux, Ubuntu, and SUSE Linux Enterprise Server.

IBM Spyre Accelerator

AI Lifecycle: Deploy Models · Serve Model

The IBM Spyre Accelerator is an AI accelerator for LinuxONE Emperor 5 systems designed to support generative AI and foundation model inference. It provides dedicated AI compute for organizations running large AI models alongside enterprise Linux workloads.

Spyre helps scale inference workloads such as large language models that enables use cases like retrieval-augmented generation (RAG), AI assistants, and other generative AI applications while allowing data and applications to remain on the LinuxONE platform.

Key Capabilities

  • Dedicated AI acceleration for foundation model inference
  • Support for a curated set of IBM Granite, Llama, Mixtral, and other transformer-based models
  • Support for online and batch inference workloads
  • Scalable architecture with support for multiple accelerator cards in a single system
  • Support for FP16, INT8, and INT4 precision formats
  • Integration with AI platforms, serving frameworks, and inference runtimes
  • No accelerator programming required for most deployments

On LinuxONE

It is designed for organizations deploying and operating generative AI workloads on LinuxONE. Common use cases include AI assistants, document intelligence, enterprise search, knowledge assistants, code modernization, and other foundation model applications.

Rather than serving as a model development platform, Spyre provides the infrastructure needed to run production inference workloads at scale.

Common Software Integrations

  • IBM watsonx.ai
  • Red Hat OpenShift AI
  • Red Hat AI Inference Server

When to Consider Spyre

Spyre may be a good fit when:

  • You need to deploy and serve foundation models on LinuxONE
  • Your AI strategy includes generative AI or large language models
  • You want to scale inference workloads while keeping applications and data on platform
  • You are building AI services using OpenShift AI, Red Hat AI Inference Server, vLLM, or Triton
