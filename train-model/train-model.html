AI on IBM Z

Train Model

Training is where your prepared data is used to create a model — iterating through algorithms, tuning parameters, and evaluating results until the model produces accurate, meaningful outputs for your business problem. On IBM Z, you can train using the tools and frameworks you already know, whether that's Python-based ML libraries, deep learning frameworks, or IBM Z's own enterprise tooling.

You don't need to train on IBM Z to deploy on IBM Z. Many teams train in hybrid cloud and bring the model to Z for inference. But IBM Z is a fully capable training platform — and training locally means your data never has to leave.

What happens at this stage?

Choose your model type

Select the right algorithm for your problem — classification, regression, clustering, or a neural network — based on your data and business goal.

Develop & iterate

Train with your prepared data, evaluate model performance, adjust hyperparameters, and compare models until you reach the accuracy you need.

Fine-tune or use pre-built

For LLMs and foundation models, fine-tune a pre-built model with your own enterprise data rather than training from scratch.

Export for deployment

Save your trained model in a portable format — PMML, ONNX, or a framework-native format — ready to move to the deploy and serve stages.

Who is this stage for?

Model training is primarily owned by Data Scientists, with ML Engineers involved in operationalizing training pipelines. IT Architects and Application Architects are stakeholders, particularly when choosing tools and platforms. Line of Business stakeholders influence what success looks like — which metrics matter and what accuracy threshold is acceptable.

Where to Start

Your starting point depends on the type of model you're building, your preferred development environment, and how your team works.

Building Traditional Machine Learning Models

You are working with structured or tabular data and need models such as classification, regression, forecasting, or recommendation systems.

→ Start with Snap ML. Snap ML is optimized for high-performance machine learning training on IBM Z and LinuxONE.

Common approach: Prepare data → Train with Snap ML → Export to PMML → Deploy.

Building Deep Learning Models

You need to develop neural networks, computer vision models, natural language processing models, or other deep learning workloads.

→ Start with TensorFlow or PyTorch. These industry-standard frameworks provide flexibility for building and training custom AI models.

Common approach: Prepare data → Train with TensorFlow or PyTorch → Export to ONNX → Optimize and deploy.

Using Python-Based Data Science Tools

You prefer Python and want to train models using familiar libraries such as pandas, NumPy, scikit-learn, TensorFlow, and PyTorch.

→ Start with Python AI Toolkit for IBM z/OS. The toolkit provides a Python runtime and curated data science environment that runs natively on z/OS.

Common approach: Explore data in notebooks → Train using Python libraries → Export and deploy the resulting model.

Training Models Within Spark Pipelines

Your data is already being processed in Apache Spark, and you want machine learning integrated directly into existing data engineering workflows.

→ Start with Apache Spark MLlib. MLlib provides scalable machine learning capabilities that operate directly within Spark pipelines.

Common approach: Process data in Spark → Perform feature engineering → Train with MLlib → Export and deploy trained models.

Building Models Directly on z/OS

You want model development, management, and operationalization integrated into the z/OS environment.

→ Start with Machine Learning for IBM z/OS (MLz). MLz provides a z/OS-native environment for developing and managing machine learning solutions.

Common approach: Develop and train models on z/OS → Manage and operationalize through MLz → Deploy.

Building an Enterprise AI Platform

Multiple teams require shared workspaces, notebooks, experiments, pipelines, and MLOps capabilities.

→ Start with Red Hat OpenShift AI. OpenShift AI provides a collaborative platform for model development, training, and lifecycle management.

Common approach: Create projects → Train using TensorFlow, PyTorch, or other frameworks → Promote models through MLOps pipelines.

Building Generative AI and Foundation Model Solutions

You want to work with foundation models, model tuning, prompt engineering, or generative AI applications.

→ Start with watsonx.ai. watsonx.ai provides access to foundation models and tools for tuning, evaluation, and AI application development.

Common approach: Select a foundation model → Tune or customize it → Deploy into business applications.
